# PC Builder

A microservices-based PC building platform for creating, customizing,
and validating PC configurations.

## Tech Stack

- Java 21
- Spring Boot 4.1.0
- Spring Cloud 2025.1.2
- Spring Cloud Gateway
- Spring Security
- Apache Kafka
- Redis
- MySQL
- Maven

## Services

- API Gateway
- Identity Service
- Catalog Service
- Compatibility Service
- Build Service
